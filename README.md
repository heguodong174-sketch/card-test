# 个人卡片生成器

一个简单易用的个人介绍卡片生成器，支持多种风格和色系选择，可以导出PNG和JPG格式的卡片。

## 功能特点

### 🎨 多样化风格
- **商务专业风格** - 适合商务人士、企业高管
- **现代简约风格** - 适合设计师、创意工作者
- **创意活泼风格** - 适合创意行业、市场营销
- **科技未来风格** - 适合IT从业者、技术专家
- **经典复古风格** - 适合传统文化工作者
- **卡通风格** - 适合教育工作者、设计师
- **渐变时尚风格** - 适合时尚从业者
- **手绘风格** - 适合艺术家、创意工作者
- **极简主义风格** - 适合作家、哲学家
- **赛博朋克风格** - 适合游戏开发者、数字艺术家
- **中国风** - 适合传统文化从业者
- **北欧风格** - 适合设计师、建筑师

### 🌈 丰富色系
- 经典商务色系（深蓝、灰色）
- 温暖橙红色系（橙、红、粉）
- 自然绿色系（森林绿、薄荷绿）
- 优雅紫蓝色系（紫、宝蓝）
- 活力黄色系（明黄、金黄）
- 清新粉色系（玫瑰粉、薰衣草紫）

### 📏 多种尺寸
- 标准尺寸 (16:9)
- 名片比例 (1.75:1)
- 正方形 (1:1)
- 垂直卡片 (9:16)

### 🔧 核心功能
- ✅ 头像上传和裁剪
- ✅ 实时预览
- ✅ 个人信息填写（姓名、公司、职位、简介等）
- ✅ 联系方式配置（邮箱、电话、地址、网站、社交账号）
- ✅ PNG/JPG格式导出
- ✅ 一键重置
- ✅ 本地数据保存

## 技术栈

- **前端**: HTML5 + CSS3 + 原生JavaScript
- **第三方库**:
  - [html2canvas](https://html2canvas.hertzen.com/) - 图片导出
  - [cropperjs](https://fengyuanchen.github.io/cropperjs/) - 图片裁剪
- **部署**: GitHub Pages

## 使用方法

### 在线使用
直接访问 [GitHub Pages](https://yourusername.github.io/card-generator/) 即可使用。

### 本地运行
1. 克隆项目
```bash
git clone https://github.com/yourusername/card-generator.git
cd card-generator
```

2. 启动本地服务器
```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8000
```

3. 在浏览器中访问 `http://localhost:8000`

## 使用步骤

1. **上传头像** - 点击头像区域上传并裁剪个人头像
2. **填写信息** - 输入个人信息、联系方式等
3. **选择样式** - 选择喜欢的卡片风格和色系
4. **调整尺寸** - 选择合适的卡片尺寸
5. **实时预览** - 所有更改会实时反映在预览区
6. **导出下载** - 点击下载按钮保存为PNG或JPG格式

## 快捷键

- `Ctrl/Cmd + S` - 保存当前数据
- `Ctrl/Cmd + R` - 重置所有内容
